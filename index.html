Turing Machine

What it is

A secret three-digit code is hidden somewhere in a set of binary sequences. Your job is to find it.

You write a short program across three slots labelled A, B and C, then test your guess against verifier cards. Each card tests one condition about the hidden sequence and answers yes or no. A verifier only runs when all three slots hold a real digit, so x — meaning “I don't know yet” — is what lets you run a card instead of guessing.

Use the answers to eliminate what cannot be true, repeat until one code remains, and submit it.

What is in this adaptation

Languages
5 — English, Español, Français, Deutsch, Пусский
Difficulty
Easy, Medium, Hard
Verifiers
3 to 7, your choice
Program slots
3 (A, B, C), each taking x or a digit 1–5
Built in
Step-by-step tutorial, verifier guide, optional cheat mode
Accessibility
Dark, light, and a colorblind mode that adds explicit glyphs, so no card state depends on colour alone
Dependencies
None. No build step, no libraries, no network requests

Level generation

The generator builds playable puzzles with a unique solution, and it works reliably. To be straight about it: it is not the official algorithm, and it is not an original invention by the author of this project. The official generator belongs to Le Scorpion Masqué and lives at turingmachine.info.
